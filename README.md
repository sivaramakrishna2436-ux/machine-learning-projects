
# Customer Churn Prediction using Machine Learning

## Project Overview
This project predicts whether a customer is likely to leave a service using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Model Evaluation
6. Churn Prediction

## Project Structure
```text
customer-churn-prediction/
├── src/
│   └── train_model.py
├── requirements.txt
└── README.md
```

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the model:

```bash
python src/train_model.py
```

## Objective
To demonstrate an end-to-end Machine Learning workflow for customer churn prediction.
